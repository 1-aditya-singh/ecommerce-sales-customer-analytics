# E-Commerce Sales & Customer Analytics System

## Project Overview

E-Commerce Sales & Customer Analytics System is an industry-oriented
data analytics and business intelligence project built for ShopSphere,
a multi-category B2C e-commerce company operating in India.

The project integrates:

- Business Requirements
- KPI Engineering
- Data Quality
- Python
- Pandas
- NumPy
- PostgreSQL
- Advanced SQL
- Statistical Analysis
- Customer Analytics
- RFM Segmentation
- Retention & Cohort Analysis
- Product Analytics
- Profitability Analysis
- Power BI
- DAX
- Business Intelligence
- Cross-System Validation

## Business Objective

The objective is to help ShopSphere use sales, customer, product,
geographic, and operational data to increase profitable growth,
improve customer retention, understand product performance, and
improve operational decision-making.
